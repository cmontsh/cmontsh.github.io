# Portfolio V3 — Deploy + SEO Setup

## 1. Replace the placeholders

Before publishing, search the project for:

- `YOUR-DOMAIN.com`
- `YOUR-USERNAME`
- `YOUR-LINKEDIN`
- `cmontsh@gmail.com`

Replace them with your real details.

## 2. Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload every file in this folder.
3. Make sure `index.html` is in the root of the repository.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and `/root`.
7. Save.

For the cleanest free URL, name the repository:

`YOUR-USERNAME.github.io`

## 3. Connect a custom domain

In **Settings → Pages → Custom domain**, enter your domain.

At your domain registrar, add the DNS records GitHub instructs you to use.

Then replace every occurrence of `https://YOUR-DOMAIN.com/` in:

- `index.html`
- `robots.txt`
- `sitemap.xml`

## 4. Submit to Google

Open Google Search Console and add your site.

Then:

1. Verify domain ownership.
2. Submit: `https://YOUR-DOMAIN.com/sitemap.xml`
3. Use URL Inspection for your homepage.
4. Click **Request indexing**.

## 5. Important SEO files included

- `robots.txt`
- `sitemap.xml`
- `favicon.svg`
- `og-card.svg`
- Schema.org Person structured data
- Open Graph metadata
- Twitter/X sharing metadata
- Canonical URL
- Custom `404.html`

## 6. Best next SEO upgrades

As your portfolio grows, create dedicated pages for:

- Research
- Publications
- Projects
- CV
- Contact

That gives search engines more useful pages to index around your name and research areas.
